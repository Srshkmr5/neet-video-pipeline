The Max Height Arc — Projectile Motion

NCERT Class 11 Part 1, Chapter 4, Page 78 • Target Duration: 66s

⚠️
CRITICAL NEET TRAP POINT

Swapping Sine and Cosine (Angle with Vertical Axis)

The textbook maximum height formula H_max = (v₀² sin²θ) / 2g is valid ONLY when angle θ is measured with the horizontal ground! If an exam question specifies angle θ relative to the vertical axis, vertical velocity becomes vy = v₀ cos θ.

H_max = (v₀² sin²θ) / 2g ➔ H_max = (v₀² cos²θ) / 2g
NEET PYQ 2024 High-Yield Trap Verification
+4 Marks / -1 Mark

A projectile is projected with an initial velocity v₀ = 50 m/s at an angle of θ = 30° with the VERTICAL. What is the maximum vertical height reached by the projectile? (Take g = 10 m/s²)

Correct! 5-Mark Examination Insight

Since angle is relative to the vertical, vertical component is vy = v0 * cos(30°).
